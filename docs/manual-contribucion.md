# Manual de Contribución - Semillero LOCXUE

¡Gracias por contribuir al proyecto web y documentación del **Semillero de Investigación LOCXUE**!

## 📋 Normas Generales

1. **Ramas principales:**
   - `main`: Código y documentación en producción.
   - `develop` o ramas de características (`feature/nombre-caracteristica`): Desarrollos y nuevas adiciones.

2. **Convención de Commits:**
   Utiliza prefijos claros para tus mensajes de commit:
   - `feat:` Nueva característica o sección web.
   - `docs:` Cambios o adición de documentación.
   - `style:` Correcciones estéticas o de CSS.
   - `fix:` Corrección de errores de código o enlaces rotos.
   - `refactor:` Optimización de estructura sin cambiar funcionalidad.

3. **Flujo de Trabajo:**
   - Crea una rama para tu aporte: `git checkout -b feature/nueva-seccion`
   - Realiza los cambios necesarios y verifica el funcionamiento.
   - Realiza commit y push a tu rama.
   - Solicita una revisión (Pull Request) hacia la rama principal.
