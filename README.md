## 🚀 Inicio Rápido

Para visualizar la página web de manera local:

1. Clona este repositorio:
   ```bash
   git clone https://github.com/sabego2006/pagina-web-locxue.git
   ```
2. Navega al directorio `web/`:
   ```bash
   cd pagina-web-locxue/web
   ```
3. Abre `index.html` en tu navegador preferido o utiliza un servidor local como Live Server.
